Governance-Reduction Pass

Preserve invariants. Liberate implementation.

Meet Snip, the red-tape goblin. He cuts tests, contracts, schemas, validators, docs, workflows, and process machinery when they fossilize implementation — while keeping a tiny shield over the guarantees real users and consumers actually depend on.

Cut ceremonyKeep invariantsPrefer diagnostics over dogma
Snip says: “I loves my ‘gun.’” He means the giant shears. We suggested “governance decompiler.” He declined comment and cut three obsolete fixtures.

Shears

Obsolete ceremony, implementation fossils, legacy process, and checks whose only assertion is “the implementation did not change.”

Shield

Observable behavior, costly regressions, public boundaries, persisted compatibility, and anything a real consumer genuinely requires.

Future freedom

The repository should be easier to evolve next week — not merely produce a cleaner diff today.

Use it

Use $governance-reduction-pass on this PR.
Apply the pass, verify it, and rewrite the PR body around the resulting system.

Install

./install.sh --dry-run
./install.sh

Hermes and portable Agent Skills copies are installed and verified by default.

Repository reality

There is intentionally no internal constitution, schema graph, generated manifest, snapshot suite, or second validator here. Nothing in this package consumes one.
